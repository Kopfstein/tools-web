# Pomodoro Timer

## Purpose

Simple timer for the pomodoro productivity method, see
[Wikipedia - Pomodoro Technique](https://en.wikipedia.org/wiki/Pomodoro_Technique).

## Core Features

1. Simple countdown timer showing minutes and seconds.
2. Buttons and input field to choose 10 min, 25 min, or custom duration.
3. Timer start button to start the countdown.
4. Play gong sound when timer expires.
